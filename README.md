## A_Shopping_Cart
Based in the previous code, this exercice is to practice API calls and basic use of DOM and OOP.
The class `shoppingCart` is responsible for storing the information and doing calculations.
The products came from the webpage https://jsonblob.com, where one can paste a JSON and lately acces to it like an API in https://jsonblob.com/api . Thanks to the creators of the web page. You can find some indications on script.js.
Look how cretae and transform elements in the DOM and how to listen events in order to atualize final prices in the shopping cart. From time to time I like to review my job and improve it.
